API komponensek: cím, paraméter, kulcs, JSON

Az első napi lekérdezésre építve megismered az API-k legfontosabb elemeit: a végpontokat, a paramétereket, a hitelesítést és a JSON-válaszok felépítését, majd ezeket a következő feladatokban már több különböző eszközben is alkalmazod.

A blokk végére
  • el tudod olvasni egy API-hívás címét: mi a végpont, mik a paraméterek, hol a kulcs;
  • eligazodsz egy JSON-válaszban;
  • tudod, mire való az API egy üzleti folyamatban.

API-alapok: kérés és válasz

Az API (Application Programming Interface) olyan programozási felület, amelyen keresztül egy szoftver más alkalmazások számára is elérhetővé teszi bizonyos funkcióit és adatait. A webes API-kat jellemzően HTTP-kérésekkel érjük el: a GET adatlekérésre, a POST pedig például új rekord létrehozására használható. A kérés tartalmazhat címet, hitelesítési adatokat a fejlécben, valamint elküldendő adatokat a törzsben; a válasz pedig HTTP-státuszkódot és gyakran JSON-formátumú adatot tartalmaz.

https://pro-api.coinmarketcap.com/v1/cryptocurrency/quotes/latest?id=1,1027&convert=EUR&CMC_PRO_API_KEY=IDE_A_KULCSOD
RészA példábanJelentés
Szolgáltatóhttps://pro-api.coinmarketcap.comAz API szerverének címe.
Végpont/v1/cryptocurrency/quotes/latestLegfrissebb árfolyamadatok lekérése.
Paraméterekid=1,1027; convert=EURBitcoin és Ethereum; euróban megadott ár.
HitelesítésCMC_PRO_API_KEYA saját kulcsod. A böngészős példában a kérés része; más API-knál külön fejléc vagy OAuth-token kell.

A JSON objektumokból, listákból, szövegekből, számokból, logikai értékekből és üres (null) értékből épülhet fel. Az objektum mezőit névvel, a listák elemeit sorszámmal éred el. A mai quotes/latest válaszban a kriptoazonosító az objektum kulcsa: "1" és "1027".

{
  "status": {
    "error_code": 0,
    "error_message": null
  },
  "data": {
    "1": {
      "name": "Bitcoin",
      "symbol": "BTC",
      "quote": {
        "EUR": {
          "price": 73102.78,
          "percent_change_24h": -1.37
        }
      }
    },
    "1027": {
      "name": "Ethereum",
      "symbol": "ETH",
      "quote": {
        "EUR": {
          "price": 2500.0,
          "percent_change_24h": 2.1
        }
      }
    }
  }
}

Érvényes JSON, kitalált árakkal; nem aktuális piaci adat. A data → 1 → quote → EUR → price útvonal a Bitcoin árához vezet. A teljes példát JSON-fájlként is megnyithatod. A null üres értéket jelent; sikeres kérésnél az error_message mező lehet null vagy üres szöveg.

Miért fontos ez üzleti szempontból?
  • Az API-k csökkenthetik a kézi adatmásolást, és lehetővé teszik az adatok automatikus, akár ütemezett továbbítását a rendszerek között. VIGYÁZAT: az automatizálás a hibás kéréseket, adatokat vagy üzleti szabályokat is következetesen végrehajtja, ezért a válaszok ellenőrzése elengedhetetlen.
  • Szinte minden modern vállalati rendszer kínál API-kapcsolatot: ilyenek például a CRM-, számlázási, banki, webshop- és futárszolgálati rendszerek.
