Harmadik nap: API és CRM a gyakorlatban

API-n keresztül kérsz le adatokat, majd API-on keresztül hozol létre új rekordot a CRM-ben. Megismered az API kérések és válaszok felépítését, megtanulod felismerni és kezelni a gyakori hibákat, végül pedig egy egyszerű példában összekapcsolod az adatlekérést a CRM-műveletekkel.

Mai témák és feladatok

A nap során megismered az API-k gyakorlati használatát Excelben és Google Sheetsben, áttekinted a Zoho CRM működését, majd API-n keresztül is létrehozol CRM-rekordokat, végül pedig egy egyszerű automatizmusban összekapcsolod az árfolyamlekérést a CRM-műveletekkel.

  • 1
    API-alapok
    Cím, végpont, paraméter, kulcs, JSON-olvasás: a nap egyetlen elméleti blokkja.
  • 2
    API az Excelben (Power Query)
    Frissülő árfolyamtábla: From Web, Into Table, kibontás, időzített frissítés.
  • 3
    API a Google Sheetsben
    Ugyanez szkripttel: beillesztés, engedélyezés, időzítő.
  • 4
    Zoho CRM kézzel
    Lead, konvertálás, deal, pipeline: megtapasztalod, mit tart nyilván a CRM.
  • 5
    Zoho API: rekord kódból
    Self Client, token, és lead-létrehozás Colabból, telepítés nélkül.
  • 6
    Árfolyamjelzés: API-k összekapcsolása
    Árfolyam-olvasás + döntés + CRM-írás egyetlen működő automatizmusban.

A gyakorlatokhoz az első napi útmutatóban létrehozott CoinMarketCap-kulcsodat és EU-s Zoho CRM-fiókodat használod. Az árfolyamtáblát Excelben vagy Google Sheetsben készítheted el; a Colabhoz Google-fiók szükséges.
